# Student Performance Analyzer

## Description
The Student Performance Analyzer is a beginner-friendly Python project that analyzes students' scores and generates useful class statistics. It demonstrates how Python functions, loops, lists, dictionaries, and conditional statements can work together to solve a real-world problem.

## Features
- Displays each student's name, score, and grade.
- Calculates the total score and average score.
- Identifies the highest and lowest scores.
- Counts the number of students who passed and failed.
- Calculates the class pass rate as a percentage.
- Handles an empty student list without crashing.

## Technologies Used
- Python 3

## Concepts Practiced
- Variables and data types
- Lists and dictionaries
- `if`, `elif`, and `else` statements
- `for` loops
- Functions and return values
- Counters and accumulators
- Basic calculations and percentages
- Handling empty lists
- Code organization and indentation

## How to Run

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

If that command does not work on your system, try:

```bash
py main.py
```
